# Setup help and support

For help choosing the manual-note, Google cloud, or Apple JSON path, [open a setup-help issue](https://github.com/jare0014/obsidian-health-connect/issues/new?template=setup_help.md).

Include your desktop OS, Obsidian version, plugin version, chosen data path, expected behavior, and a redacted error message. Use synthetic records when sharing an example. Never attach OAuth credentials, tokens, plugin `data.json`, or personal health exports.

This is beta software. Responses are best effort; there is no guaranteed response time or advertised paid setup package. Donations support development and do not purchase a service commitment.

The current manifest enables desktop only. Android Health Connect access and mobile plugin execution are not supported paths in this release. A phone can prepare an Apple JSON export for ingestion by desktop Obsidian.

Start with the [account-free demo](docs/TRY-THE-DASHBOARD.md). Cloud authorization and successful read/write operations require separate validation with your account.
